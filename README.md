## 📝 Manual de Markdown

### 1. Títulos

Use `#` no início da linha. Quanto mais `#`, menor o título (de 1 a 6).

```md
# Título 1
## Título 2
### Título 3
```

### 2. Ênfase (negrito, itálico e tachado)

```md
*itálico* ou _itálico_
**negrito** ou __negrito__
***negrito e itálico***
~~tachado~~
```

Resultado: *itálico*, **negrito**, ***negrito e itálico***, ~~tachado~~

### 3. Listas

**Não ordenada:**
```md
- Item 1
- Item 2
  - Subitem 2.1
```

**Ordenada:**
```md
1. Primeiro passo
2. Segundo passo
3. Terceiro passo
```

**Checklist (tarefas):**
```md
- [x] Tarefa concluída
- [ ] Tarefa pendente
```

### 4. Links

```md
[Texto do link](https://exemplo.com)
```

### 5. Imagens

```md
![Texto alternativo](https://exemplo.com/imagem.png)
```

### 6. Código

**Inline:** use crase simples: `` `variavel = 10` ``

**Bloco de código** (com destaque de sintaxe, indicando a linguagem depois das três crases):

````md
```csharp
int idade = 20;
Console.WriteLine(idade);
```
````

### 7. Citação (blockquote)

```md
> Isso é uma citação.
> Pode ter várias linhas.
```

> Isso é uma citação.

### 8. Tabelas

```md
| Variável | Tipo   | Valor |
|----------|--------|-------|
| idade    | int    | 20    |
| nome     | string | "Zero"|
```

| Variável | Tipo   | Valor |
|----------|--------|-------|
| idade    | int    | 20    |
| nome     | string | "Zero"|

### 9. Linha horizontal

```md
---
```

### 10. GIFs

Um GIF nada mais é do que uma imagem animada — usa-se **a mesma sintaxe de imagem** (`![]()`), só que o link aponta para um arquivo `.gif`:

```md
![Descrição do gif](https://link-direto-para-o.gif)
```

### 11. Desenho / imagem

Assim como o gif, um desenho ou foto também usa `![]()`:

```md
![Meu desenho](./imagens/meu-desenho.png)
```

Se quiser algo rápido sem precisar de arquivo de imagem, dá pra fazer **arte em ASCII** dentro de um bloco de código:

```
   _____
  /     \
 | () () |
  \  ^  /
   |||||
   |||||
```
